🐶 Dog World

Welcome to Dog World! This is a simple and beginner-friendly website about dogs, built using HTML, CSS, and JavaScript.

The website introduces visitors to dogs, showcases popular dog breeds, and provides basic tips for caring for dogs.

🌟 Features
🐕 Home Section: Welcome message and a cute Golden Retriever image.
🦴 Popular Dog Breeds: A list of popular dog breeds, including Golden Retriever, German Shepherd, Labrador Retriever, Beagle, and Pug.
🐾 Dog Care Tips: Helpful tips about feeding, hydration, exercise, hygiene, and affection.
🎨 Attractive Design: Warm colors, rounded sections, and a simple, user-friendly layout.
🖱️ Interactive Button: A button that displays a fun message about dogs using JavaScript.
📱 Responsive Image: The dog image adjusts to fit smaller screens.
🛠️ Technologies Used
HTML5 – Structures the webpage.
CSS3 – Styles the website and creates its layout.
JavaScript – Adds interactivity to the button.

🚀 How to Run the Project
Clone or download this repository.
Open the project folder.
Open index.html in your web browser.
Explore the different sections and click the interactive button.

No additional installations or dependencies are required.

🖼️ Image Source

The Golden Retriever image is loaded from Unsplash.

An internet connection is required to load this external image.

🎯 Project Purpose

This project was created to practice the fundamentals of HTML, CSS, and JavaScript while building a simple, attractive, and interactive website.
